Settings reference

Main window

The main window controls instances, account workflow, timing, packs, detection, notifications and startup actions.

Built-in help is available. Hover over a control in PTCGPB to see a short explanation. This page provides the expanded reference.

Friend and instance settings

Setting Purpose Default / format
Friend ID Main account used for friend requests and God Pack testing. Only appears where relevant. 16 digits, no spaces or dashes
Instances Number of numbered MuMu instances run in parallel. Main instances are not included. 1
Columns Maximum instance windows in each row when arranging them. 5
Arrange Moves recognized MuMu windows into a grid on the selected monitor. Uses Columns and Row Gap
Instance Start Delay Seconds between starting one bot script and the next. 10 seconds
Run Main(s) Starts and uses Main account instances in Wonderpick mode. Off
Mains Number of Main instances. Name them Main, Main2, etc. 1

Bot settings

Setting Purpose Availability
Bot Mode Selects the account workflow. See Bot modes. Always
Force inject accounts Bypasses normal account eligibility once per account. A stored FI flag prevents the same account from being forced again until the flags are cleared. Inject 13P+, Wonderpick and Rewards
Clear force inject flags Clears FI from all account metadata so each account can be force-injected once again. Always visible
Min Packs Minimum saved pack count required for Wonderpick injection. Valid range 70–999. Inject Wonderpick 96P+
One pack at a time Removes and re-adds friends between each opened pack. Inject Wonderpick 96P+
Open Extra Pack Opens one extra pack after the two free packs. Inject modes except Rewards
Spend Hourglasses Uses the loaded account's hourglasses for more packs. Inject 13P+ and Wonderpick
10-pack opening Uses the ten-pack opening option while spending hourglasses. Inject 13P+ with Spend Hourglasses
Hourglass pack count Number of hourglass packs to open. 0 means as many as possible; maximum 999. When Spend Hourglasses is enabled
Sort By Orders saved accounts using stored metadata. Inject modes and Rename Account
Account Name Prefix used for newly created or renamed accounts. PTCGPB adds a random number. Create Bots (13P) and Rename Account

Configuration sections

Pack Selection

Choose which booster expansions can be opened. At least one should be selected.

Choose which high-value Wonderpick pulls trigger saving and notification in Inject Wonderpick 96P+.

Save for Trade

Choose tradeable rarities and optional synthetic screenshot behavior.

Configure shared friend lists, VIP lists and automatic GP testing.

Discord Settings

Set notification destinations, account XML attachments and heartbeat reports.

Tools & System

Configure MuMu, monitor, OCR, helper tools, daily actions, logging and Cockpit.

Time settings

Setting Purpose Default
Delay Milliseconds between bot actions. Increase it when clicks are missed or screens have not finished loading. 250 ms
Swipe Speed Duration of card and menu swipe gestures. Use the in-app tooltip for the recommendation matching your speedmod setup. 250 ms
Wait Time Seconds to wait after sending friend requests so they can be accepted. 5 seconds

Actions and icons

Control What it does
Balance XMLs Redistributes saved account XML files evenly between numbered instance folders.
Launch All MuMu Starts all configured numbered and Main MuMu instances.
Start Bot Validates and saves settings, then starts the instance scripts.
Open Card Database Opens the local collection dashboard for saved accounts.
Discord icon Opens the PTCGPB community server.
Help icon Opens the online user guide.
Tools icon Opens Tools & System settings.
