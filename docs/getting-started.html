Getting started

Prepare MuMu Player, confirm the game can be controlled, and test the bot with one instance before scaling up.

Before you start

You need

  • Windows and the latest official MuMuPlayer with an Android 12 instance.
  • AutoHotkey v1.1 installed. AutoHotkey v2 is not supported.
  • PTCGPB extracted to a writable folder whose full path contains no spaces.
  • The supplied ready2go MuMu instance backup.
  • Administrator permission when PTCGPB requests it.

Recommended for the first test

  • Use exactly one numbered instance.
  • Leave timing values at their defaults.
  • Keep advanced group and Discord features disabled.
  • Watch one complete run before adding instances.

Prepare MuMu Player

  1. Install the current MuMuPlayer

    Download the latest version from the official MuMuPlayer website and use an Android 12 instance for PTCGPB.

  2. Restore the ready2go instance

    In MuMuPlayer, restore the ready2go instance (see discord for the latest version). This is the recommended starting point because it already contains the expected Android 12 environment and game preparation.

  3. Name the restored instance exactly 1

    PTCGPB locates numbered instances by their exact title. Later instances must be cloned from the working instance and named 2, 3, and so on without gaps.

  4. Set the game language

    Remember the client language. You will select the matching value under Tools & System. OCR works best when its language also matches your Windows display language.

  5. Start the instance

    You can start it in MuMu or use Launch All MuMu in PTCGPB after the MuMu folder is configured.

Configure PTCGPB

  1. Check the PTCGPB folder

    Move the complete bot folder if any part of its path contains a space. For example, use C:\PTCGPB, not C:\My Bots\PTCGPB.

  2. Launch PTCGPB.ahk with AutoHotkey v1

    Approve the administrator permission prompt. On the first run, select the bot interface language.

  3. Open Tools & System

    Select the monitor, verify the MuMu parent folder, and set the OCR and game client languages. The default MuMu parent folder is C:\Program Files\Netease.

  4. Set Instances to 1

    Set Columns to 1 for the first test. Instance Start Delay can remain at its default of 10 seconds.

  5. Choose a bot mode

    Use Bot modes to understand what each mode does to accounts. New users normally begin with Create Bots (13P).

  6. Select packs and timing

    Choose at least one expansion. Start with Delay 250 ms, Swipe Speed 250 ms and Wait Time 5 seconds.

  7. Arrange and start

    Use Arrange to check that PTCGPB recognizes the MuMu window, then select Start Bot.

Do not scale up yet. Let one instance finish a complete account cycle. Confirm that clicks, swipes, OCR and account saving behave correctly before increasing the Instances value.

Adding a Main account

A Main account is useful only when you intend to run Inject Wonderpick 96P+. It accepts friend requests and performs God Pack tests. You do not need a Main for Create Bots, Inject 13P+ or Inject Rewards.

  • Name its MuMu instance exactly Main.
  • Name additional main instances Main2, Main3, and so on.
  • Enable Run Main(s) where it appears and enter the number of Main instances.
  • Enter the 16-digit Friend ID without spaces or dashes when the selected workflow uses the Friend ID field.

After the first successful run

Add numbered MuMu instances one at a time. Increase Instance Start Delay or Launch MuMu Delay if startup overloads the PC. Use Auto-open Monitor once unattended runs are stable.
