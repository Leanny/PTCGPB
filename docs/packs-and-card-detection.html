Pull configuration

Packs, Inject 96p Card Detection and S4T

Choose which expansions the bot opens and which high-value Wonderpick results it saves or reports, and which tradeable pulls Save for Trade keeps across pack-opening modes.

Pack Selection

Select the booster expansions the bot may open. Packs are grouped by series, with newly added packs potentially appearing under Uncategorized until the list is updated.

The current pack catalog includes Team Rocket’s Ambition. Its addition also changes the home-screen pack positions, so review saved selections after updating.

  1. Open Pack Selection

    Select the button in the gold Pack Selection section of the main window.

  2. Select one or more packs

    Use the checkboxes beside the expansions you want the bot to open.

  3. Select Apply

    The main-window button updates to summarize the selection. Cancel closes the dialog without applying changes.

Review after game updates. When expansions are added or removed, reopen Pack Selection and confirm that the intended packs remain selected.

Inject 96p Card Detection

These options apply specifically to Inject Wonderpick 96P+ and decide which Wonderpick results count as worth saving and notifying. They are not the trade-detection settings. Detection rules can overlap; enabling several rules broadens what the bot keeps.

Option Behavior
Min GP 2★ Minimum number of two-star cards a detected God Pack must contain to be considered valid.
Single Full Art 2★ Saves and reports a pack containing a two-star Full Art card.
Single Trainer 2★ Saves and reports a pack containing a two-star Trainer card.
Single Rainbow 2★ Saves and reports a pack containing a two-star Rainbow card.
Double 2★ Saves and reports a pack containing two two-star cards, sometimes called a pseudo God Pack.
Wishlist 2★ Saves and reports a wishlisted two-star Trainer, Full Art or Rainbow card from the Card Database wishlist.
Ignore Invalid Packs Suppresses Discord messages for God Packs detected as invalid. They are still logged and backed up.

Choosing sensible rules

Focused testing

Enable only the rarities you actually want to Wonder Pick. This produces fewer notifications and a smaller review queue.

Broad collection building

Enable multiple single-card rules and Wishlist detection. Expect more saved accounts and Discord posts.

Wishlist detection

  1. Open Card Database

    Use the button below Save for Trade on the main window.

  2. Maintain your wishlist

    Mark the desired cards in the database dashboard.

  3. Enable Wishlist 2★

    Open Inject 96p Card Detection and enable the wishlist rule. Only supported two-star card categories trigger this rule.

Save for Trade (S4T)

Save for Trade checks opened packs for the tradeable rarities you select. When a pack matches, PTCGPB saves the account locally and sends the result to your configured S4T Discord webhook. S4T is available in Create Bots (13P), Inject 13P+ and Inject Wonderpick 96P+. It does not process pulls in Inject Rewards because that mode does not open packs.

S4T is separate from Inject 96p Card Detection. Inject 96p Card Detection identifies pulls for the Wonderpick workflow. S4T identifies cards you want to keep for trading. In Inject Wonderpick 96P+, you may enable both systems at the same time.

S4T options

Option Behavior
Enable S4T Turns Save for Trade processing on.
Rarity checkboxes Select any combination of three-diamond, four-diamond, one-star, shiny, two-star Trainer, Rainbow, Full Art, two-star Shiny, Immersive, Crown Rare and Wishlist pulls.
Wonder Pick In Inject Wonderpick 96P+, only reports packs worth Wonder Picking from your Main. Packs below Min. Cards are skipped.
Min. Cards Minimum number of matching tradeable cards required when Wonder Pick is enabled. Valid values are 1 and 2.
Save Screenshots Keeps generated pack screenshots in the Screenshots folder after sending them to Discord.
Use Synthetic Screenshots Builds the pack image from card artwork where possible instead of capturing the emulator screen.
Track Shinedust Reads the shinedust total with OCR and stores it in account metadata.

Set up S4T

  1. Choose a pack-opening mode

    Select Create Bots (13P), Inject 13P+ or Inject Wonderpick 96P+, then confirm the intended packs in Pack Selection.

  2. Open Save for Trade

    Select the Save for Trade button on the main window and enable S4T.

  3. Select the pulls to keep

    Enable each rarity you want to save and report. If using Wishlist, first maintain the wishlist in the Card Database.

  4. Configure Wonder Pick filtering

    In Inject Wonderpick 96P+, optionally enable Wonder Pick and choose whether a reported pack needs one or two matching tradeable cards.

  5. Choose screenshot and shinedust options

    Synthetic screenshots are normally faster and more reliable. Enable Save Screenshots only when you want to retain copies after Discord delivery. Enable Track Shinedust when that metadata is needed.

  6. Apply the S4T settings

    Select Apply and verify that the Save for Trade button shows S4T as enabled with the expected rarities.

  7. Configure the S4T Discord destination

    Open Discord Settings and enter the S4T Discord user ID and S4T webhook URL. Enable Send Account XML only for a private, trusted channel because the XML contains account data.

  8. Review the start confirmation

    When starting the bot, confirm that S4T is enabled and that the displayed rarity list matches your intended setup.

Back up local account data. Keep copies of both Accounts\Saved and Accounts\Cards\accounts. Never post a Discord webhook URL or account XML publicly.

Detection troubleshooting

Too many packs are being reported
Disable broad single-card rules you do not need, raise Min GP 2★ where appropriate, or enable Ignore Invalid Packs to suppress invalid detections.
Wishlist pulls do not trigger
Verify that the exact card is wishlisted in the local Card Database and that it is a supported two-star Trainer, Full Art or Rainbow card.
