Tools and system

Configure daily actions, event missions, MuMu Player, language recognition, monitoring and account utilities.

Account actions

Option Behavior
5x Showcase Likes Gives five showcase likes daily to Friend IDs in showcase_ids.txt, one ID per line. The counter is shared across instances and resets at server reset.
Claim Daily 4 Hourglasses Claims the daily mission reward of four hourglasses on each account.
Receive Gift Opens received gifts on each account.
No Speedmod Menu Clicks Skips 1x/2x/3x ModMenu buttons. Enable only when running without the speedModMenu.
Use ids.txt in Solo Reroll Uses Friend IDs from ids.txt in the bot folder instead of only the main Friend ID field.
Save Name + Friend Code Stores each account's in-game name and Friend ID in its metadata. Hidden in Create Bots mode.

Special Event Missions

Control Purpose
Special Event Extractor Captures the current event's missions from the game and saves the .sevt definition used by the bot.
Reset Claim Status Clears the X flag and per-event claim counts so special missions can be attempted again. This is a recovery tool, not a required step for each new event.
Reset Receive Gift Status Clears gift history so the bot tries to open gifts again on every account.
In-Depth History Import Checks history days that already contain entries and imports individual missing card occurrences. It takes longer than the normal import and runs independently of the H flag until disabled.
Clear Pull History Opens two recovery choices. Clear pull history removes recorded pulls and resets the H flag; Only clear history flag keeps existing pulls and allows another import. Traded and shared card records are preserved.
Claim Rewards Claims rewards for configured special event missions.
Wonderpick Performs Wonder Picks when required by an event mission.

Special Event Extractor fields

Field Meaning
Claim Steps (Days) Number of daily event steps to track. Use 1 for a one-time claim.
Claim Days Optional comma-separated steps on which the claim UI is used, such as 3,5. Empty means every step.
Gift Days Optional comma-separated steps on which gift collection is forced. Empty means no forced gift days.
Elite Deck event Marks an event whose claim awards a deck. PTCGPB restarts the game after a successful claim and registers the deck cards in the Card Database without sending a Discord notification.

Each active .sevt event keeps its own claim count and last-claim time in account metadata. Inject Rewards can therefore discover a new event or the next daily step without requiring a global Claim Status reset. Event game days follow the expiry time stored in the event definition; the extractor defaults to 05:59:59 UTC.

Reset buttons affect all account metadata. Use them only when you intentionally want every account to repeat the corresponding action.

Language settings

OCR is the language Windows uses to recognize text from the game. Client is the language selected inside Pokémon TCG Pocket. Select matching languages whenever possible.

OCR choices: en, zh, es, de, fr, ja, ru, pt, ko, it, tr, pl, nl, sv, ar, uk, id, vi, th, he, cs, no, da, fi, hu, el, zh-TW.

Client choices: en, es, fr, de, it, pt, jp, ko, cn.

Monitoring and storage

Option Behavior
Auto-open Monitor Starts the Monitor with the bot. Monitor watches instances and restarts ones that become stuck.
Auto-open Cockpit Starts the live status and metrics dashboard. Hidden in Create Bots mode.
Backup to Git Commits and pushes the categories selected in Backup settings on the shared backup interval. The bot folder must be a git repository.
Backup to Disk Copies the selected categories to a chosen folder while preserving their relative paths. The destination cannot be the bot folder or one of its subfolders.
Backup settings... Sets the shared interval (minimum five minutes), disk destination and included data. Backup Now immediately performs a disk backup and also a Git backup when enabled.
Log Level Controls log detail: error, warn, info, debug or trace. Use info normally.

Backup categories include account XML and JSON data, Settings.ini, showcase and manual VIP IDs, God Pack test lists, and active or past .sevt event definitions. At least one category must remain selected.

In Cockpit's Injection Queue, the God Pack status filter shows accounts with an active T flag. Their remaining five-day T-flag cooldown is included in Ready In. Right-click an account and choose Reset God Pack (T) Flag to make it eligible again.

For support investigations: temporarily use debug or trace only when asked or when reproducing a problem. Higher levels create much more log output.

Account tools

XML Duplicate Remover removes duplicate saved accounts, keeping the copy with more packs or the older one. XML Account Manager analyzes, renames and separates XML files using metadata. Back up both Accounts\Saved and Accounts\Cards\accounts before either operation.

Version Manager

Version Manager retrieves releases from the configured PTCGPB GitHub repository. Choose the stable channel for normal releases or beta to include prereleases, then use Save & Refresh to update the release list. Prerelease builds automatically follow the beta channel.

  • Automatic notifications checks the selected channel at startup and offers newer releases.
  • Install selected can upgrade, reinstall or, after an extra warning, downgrade.
  • Release bundles are SHA-256 checked when a checksum is supplied. Files being replaced are copied to a dated folder under Backups before installation.
  • Managed updates preserve settings, saved accounts, logs, screenshots and event data.
  • Before replacing files, the updater closes the Card Database helper programs. If either helper cannot be stopped, installation is cancelled without replacing files.
