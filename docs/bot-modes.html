Core workflow

Bot modes

The selected mode determines where accounts come from, what the bot does with them and which settings are visible.

Mode Account source Main purpose Result
Create Bots (13P) New accounts Create and open the initial packs Accounts are saved as XML for later use
Inject 13P+ Saved accounts Open available and optional hourglass packs Processed accounts are marked as used

Create Bots (13P)

Creates brand-new game accounts, opens their initial packs and saves each account as an XML file.

New accountsNo saved account requiredAccount Name visible

Relevant settings

  • Account Name: prefix assigned to newly created accounts.
  • Pack Selection: expansions the bot is allowed to open.
  • Save for Trade: can save and report pulls matching your selected tradeable rarities.
Use this first. Create Bots builds the pool of saved XML accounts that the Inject modes consume later.

Inject 13P+

Loads saved accounts, opens their available packs and then marks the accounts as used.

Saved XML accountsOptional hourglassesSorting available

Relevant settings

  • Open Extra Pack: opens one pack after the two free packs.
  • Spend Hourglasses: uses the account's hourglasses for additional packs.
  • 10-pack opening: uses the ten-pack option when spending hourglasses.
  • Pack count: maximum packs to open using hourglasses. Enter 0 to use as many hourglasses as the account allows.
  • Sort By: chooses which saved accounts enter the queue first.

S4T: Enable Save for Trade if these pack openings should report selected tradeable pulls.

Inject Wonderpick 96P+

Loads accounts that meet the minimum pack count, friends your Main accounts, opens packs for God Pack testing and unfriends at the end.

Main accountFriend requestsGod Pack testing

Relevant settings

  • Friend ID: the Main account's 16-digit Friend ID.
  • Run Main(s): runs the MuMu instances named Main, Main2, and so on.
  • Min Packs: eligibility threshold from 70 to 999; default 96.
  • One pack at a time: removes and re-adds friends between each pack.
  • Wait Time: pause after friend requests so the Main has time to accept them.
  • Inject 96p Card Detection: defines which Wonderpick pulls count as worth keeping or reporting.
  • Save for Trade: independently saves and reports pulls matching the selected tradeable rarities.

Inject Rewards

Loads saved accounts to perform selected maintenance and reward actions without opening packs. Accounts remain available for other modes.

No pack openingAccounts remain available

When starting this mode, a confirmation window lets you choose:

  • Save Name + Friend Code
  • Wonderpick
  • Claim Daily 4 Hourglasses
  • Claim Special Missions
  • Receive Gift
  • Track Shinedust

You may leave every option unchecked to only log in and out.

Special-event eligibility is tracked separately for each active .sevt definition and each account. New events and later daily claim steps can therefore enter the queue without resetting global Claim Status. For an event marked as Elite Deck, PTCGPB restarts the game after a successful claim and stores the awarded deck cards in the Card Database.

Rename Account

Loads saved accounts and changes their in-game names without opening packs. Accounts remain available for pack-opening and reward modes.

Saved XML accounts31-day eligibilityAccounts remain available

Relevant settings and behavior

  • Account Name: when set, the new name is the prefix plus a random number and is limited to 14 characters. When empty, PTCGPB chooses a name from usernames.txt, or from usernames_default.txt when the custom file does not exist.
  • Sort By: controls the order in which eligible saved accounts are processed.
  • PTCGPB requires 31 full days from any recorded creation time and last rename. An in-game cooldown response also causes the account to be skipped.
  • The mode scans all saved XMLs, including accounts that were already marked as used by a pack-opening mode.

Force inject accounts

This main-window option is available in the three Inject modes. It bypasses their normal eligibility rules once per account, including cooldowns, pack thresholds and used status. PTCGPB records an FI metadata flag as soon as an account is claimed so concurrent instances do not force-inject the same account.

Use Clear force inject flags to make all accounts eligible for one more forced pass. This reset changes account metadata, so back up account data first.
