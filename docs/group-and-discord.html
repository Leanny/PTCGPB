Group and Discord

Send results to the correct channels, monitor instances remotely, and participate in a shared reroll group.

Keep webhook URLs secret. Anyone with a Discord webhook URL can post through it. Use private channels for account XML attachments and replace a webhook immediately if it is exposed.

Discord destinations

Section Used for Fields
Solo Reroll InjectWP Your own reroll and Wonderpick results. Discord ID, Webhook URL, Send Account XML
Group Reroll InjectWP God Pack results shared with a reroll group. Group Discord ID, group Webhook URL, Send Account XML
Save for Trade Tradeable card results selected in S4T settings. S4T Discord ID, S4T Webhook URL, Send Account XML
Heartbeat Periodic instance and pack-opening status. Name, three webhook destinations, delay

A Discord ID is used to mention the intended user. A webhook URL decides which channel receives the message.

Heartbeat

Enable Heartbeat to post a status report every configured number of minutes. Reports show which instances are online or offline, total packs opened and packs per minute.

Setting Purpose
Name Heading shown at the top of heartbeat posts.
Solo HB Webhook Normal heartbeat for your own bot.
Solo Detailed HB Webhook Detailed per-instance counts, update times and owner alerts such as recognition failures and restarts.
Group HB Webhook Heartbeat destination shared by the reroll group.
HB Delay Minutes between reports. Default: 30.

Group Reroll

Group Reroll downloads shared Friend ID lists and allows the Main instance to run God Pack tests for the group.

Setting Purpose Default
Enable Group Reroll Enables the shared reroll workflow. Off
ids.txt API URL Address from which numbered instances download the group's shared Friend ID list. Provided by the group
vip_ids.txt API URL Address from which Main downloads VIP accounts that found God Packs. Main favorites them and does not remove them during tests. Provided by the group
Auto GPTest Starts a Main-account GP test at a regular interval. Off
Test Time Seconds between automatic GP tests. 3600 (1 hour)
GP Test mode Standard runs a normal test. Unopened Pack requires an account that still has an unopened booster pack. Standard
GP Test Wait Seconds Main waits for instances to remove friends before Main removes non-VIP friends. 150

Group setup checklist

  1. Get the shared URLs

    Obtain the exact ids.txt and vip_ids.txt endpoints from your group administrator.

  2. Configure group Discord

    Add the group user ID and webhook. Ask whether attaching account XML files is permitted.

  3. Configure Main

    Name its instance Main, enable Run Main(s), and test friend removal manually before enabling automatic GP tests.

  4. Enable automation last

    Start with Standard mode. Enable Auto GPTest only after a manual test completes successfully.

Solo IDs file

Use ids.txt in Solo Reroll, found in Tools & System, makes solo instances use ids.txt in the bot folder instead of only the Friend ID field. Put one 16-digit Friend ID on each line.
