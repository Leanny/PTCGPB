How the pieces fit together

  1. Account data stays on your PC

    PTCGPB stores game accounts locally rather than inside MuMu. MuMuPlayer provides the Android 12 instances in which the bot temporarily runs those accounts. A Main instance is only useful for Inject Wonderpick 96P+.

  2. PTCGPB saves your choices

    The main window controls the mode, number of instances, selected packs, detection rules and notifications.

  3. Accounts move through a workflow

    Create Bots produces local account XML files in Accounts\Saved. Saved-account modes load those accounts into MuMu later to open packs, test Wonder Pick availability, collect rewards or rename eligible accounts.

  4. Monitor and Cockpit provide oversight

    Monitor watches for stuck instances. Cockpit shows live status and metrics for running instances.

Useful terminology

Term Meaning
Instance A numbered MuMu Player copy named 1, 2, 3, and so on.
Main Your primary game account in a MuMu instance named Main. Additional mains are named Main2, Main3, and so on.
Inject Load a previously saved account XML into MuMu so the bot can use that account again.
God Pack / GP A high-value pack recognized by the configured card-detection rules.
Save for Trade / S4T Save and report accounts that pulled selected tradeable card rarities.
Heartbeat A periodic Discord status report containing instance and pack-opening information.
