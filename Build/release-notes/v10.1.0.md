## Highlights

- Added configurable backups to disk and Git, with a shared schedule, selectable data categories and a **Backup Now** action.
- Added an in-depth history import that can recover individual missing cards from days that were already imported.
- Replaced **Clear History Flag** with **Clear Pull History**, offering either a full pull-history reset or an H-flag-only reset. Traded and shared card records are preserved.
- Reworked shinedust OCR to read from the Trade screen, with a My Cards/Flair fallback for newer accounts and improved parsing and recovery.

## Cockpit and account workflows

- Added a **God Pack** filter to Cockpit's Injection Queue, made active T flags affect the displayed cooldown, and added a context-menu action to reset an account's T flag.
- Reworked dashboard-initiated friend requests to use the regular Inject Wonderpick flow, including tutorial, popup and retry handling.
- Fixed Balance XMLs so accounts with duplicate filenames receive unique names instead of being overwritten.

## Reliability and usability

- Consolidated MuMu installation-path discovery across the main app, injection/extraction tools and Special Event Extractor.
- Improved Special Event Extractor field layout and added hover explanations for claim steps, claim days and gift days.
- The updater now stops running Card Database helper processes before replacing files and aborts safely if they cannot be stopped.
- Added a settings snapshot to run logs and corrected result/status log formatting.
- Fixed the daily mission claim click and other event-extractor, OCR and account-management edge cases.
