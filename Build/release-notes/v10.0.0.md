Please take a backup of your bot folder before updating, just in case something might go wrong!

## Highlights

- Switched to a different git repository.
- Added a new Version Manager with access to pre-releases.
- Overhauled the Card Database with a new one that displays every card on your account.
- Overhauled the metadata management of accounts to allow for more fine-granular injections and status updates.
- Added the Cockpit live dashboard for monitoring instance state, runtime, readiness, cooldowns, and injection activity.
- Added a full XML Account Manager for analyzing, filtering, reporting, sorting, separating, and batch-renaming saved account XMLs.
- Added complete in-app documentation covering setup, bot modes, the main window, accounts and trading, packs and detection, tools, troubleshooting, and the Discord workflow.

## Automation and account management

- Added optional 10-pack opening for Inject 13P+ and configurable Spend All Hourglasses runs.
- Added a one-time Force Inject option that bypasses normal account eligibility.
- Added a Rename Account bot mode.
- Added option to generate higher quality images than using in-game screenshots.
- Added MuMu Player v6 base support, more reliable installation and instance discovery, and support for both 100% and 125% Windows display scaling.
- Added hover help throughout the main UI, improved settings organization, locked the main window during active runs, and ordered packs by release date.

## Card Database and trading

- Added card names to Discord notifications and automatic refresh when new cards initially resolve to placeholder names.
- Added wishlist finding.

## Events and rewards

- Added per-account, multi-day special-event progress to manage events properly.
- Added Elite Deck event support, including card/Shinedust registration, delayed reward handling, and restart recovery.
- Added handling for Welcome Back screens and missions, Welcome-screen restarts, Wonder Pick tutorials, and event layouts that shift mission controls.

## Upgrade notes

- Settings, saved XMLs, account metadata, collections, event definitions, logs, and screenshots are excluded from managed update replacement.
- The updater creates a timestamped backup under `Backups` before replacing files and validates the release bundle before installation.
- The first Card Database launch may take longer while the new SQLite index and repair snapshot are built; later launches and updates are incremental.
